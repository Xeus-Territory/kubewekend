📖 Monitoring Concepts Reference

📈 Metrics (Prometheus)

  • Counter: http_requests_total, auth_attempts_total, db_operations_total
  • Histogram: http_request_duration_seconds, db_query_duration_seconds
  • UpDownCounter: active_connections, active_db_sessions

🔗 Trace → Log → Profile Correlation

  • Every log includes trace_id and span_id
  • Grafana links: Trace → Logs (by trace_id) → Profile (by time range)
  • Error spans have events with failure reason details
